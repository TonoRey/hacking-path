Concepts Covered
Passive Reconnaissance
Gathering information about a target using only publicly available data — no direct interaction with the target's systems. Includes WHOIS, search engines, cached pages, public DNS records, and reviewing publicly accessible code/pages. Zero footprint on the target.
PASSIVE RECON
Active Reconnaissance
Directly interacting with a target system to gather information — port scanning, service probing, directory brute-forcing. Leaves traces in server logs. Requires explicit written authorization from the system owner. Line between ethical and illegal.
RECON
WHOIS
A protocol/database that stores registration info for internet resources (domains, IP blocks). Returns: registrar name, creation/expiration dates, nameservers, and (pre-GDPR) registrant contact info. Post-GDPR most personal data is masked by privacy services.
OSINT
Domain Registrar
A company accredited by ICANN to sell and manage domain name registrations. Acts as the "notary of the internet." Examples: GoDaddy, Namecheap, Tucows. You don't buy domains — you lease them. If you stop paying, you lose the domain.
OSINT
ICANN
Internet Corporation for Assigned Names and Numbers. The global non-profit that coordinates the DNS root, IP address allocation, and domain name policy. Think of it as the governing body of internet namespaces.
OSINT
Data Breach / HIBP
A data breach is an incident where private information is exposed without authorization. Have I Been Pwned (HIBP) is a free service by Troy Hunt that aggregates known breaches and lets you check if your email/password appeared in them. Industry-standard reference.
DEFENSE
Password Manager / Vault
Software that generates, stores, and autofills strong unique passwords for every site, encrypted with a single Master Password. The vault is the encrypted container where all credentials live. Zero-knowledge: even the provider can't see your passwords.
DEFENSE
Credential Stuffing
An automated attack where stolen email+password pairs from breaches are tested against other services. Works because people reuse passwords. One compromised breach can cascade into bank, email, and social media access. The Synthient 2025 breach relevance.
THREAT
Security Headers (HTTP)
HTTP response headers that instruct browsers on security behavior. Key headers: HSTS (force HTTPS), CSP (prevent XSS), X-Frame-Options (prevent clickjacking). Absence of these headers is a detectable vulnerability via passive analysis.
WEB SEC
Meta Pixel Tracking
A JavaScript snippet from Meta (Facebook) that records page visits and user behavior. When placed on login pages, it reports authentication attempts to Meta's servers — a privacy concern. Detectable by reading a site's HTML source code.
PRIVACY
GDPR & Privacy Masking
The EU's General Data Protection Regulation (2018) required domain registrars to mask personal data in public WHOIS records. This is why most .com WHOIS now shows "Domains By Proxy" instead of real names. The data still exists — it's just not publicly accessible.

Golden Rules — Ethical Hacking
01
Written authorization before active testing. "My friend knows I'm testing" is not authorization. You need explicit, documented permission defining the scope before any active interaction with a third-party system.
02
Passive recon is always legal. Analyzing publicly available information — WHOIS, HTML source, DNS records, security headers — touches nothing that isn't already public. This is where learning starts safely.
03
Offensive practice = your own lab only. When studying attack techniques (Q3), you run them exclusively against your own machines or intentionally vulnerable VMs (DVWA, HackTheBox). Never against real systems you don't own.
04
Verify before acting. Before executing any tool or recommendation — double check the info. Ask Claude to verify current accuracy. Tools change, vulnerabilities get patched, recommendations evolve.
05
Disclose responsibly. If you discover a real vulnerability in a third-party system during passive analysis — report it to the owner privately before any public disclosure. Give them time to fix it.
